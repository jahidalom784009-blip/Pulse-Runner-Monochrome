# Pulse Runner — 2D Platformer

An original black-and-white minimalist side-scrolling platformer inspired by the broad genre and feel of games such as Rodha. It does not copy Rodha's proprietary art, levels, or source code.

Features: running, jumping, gaps, spikes, collectible energy orbs, score, best score saved locally, mobile controls, pause/resume, PWA offline shell.

## GitHub Pages
1. Create a public GitHub repository (e.g. `pulse-runner`).
2. Extract this ZIP and upload every file in this folder to the repository root.
3. Go to Settings → Pages.
4. Under Build and deployment choose `Deploy from a branch`, branch `main`, folder `/(root)`, then Save.
5. Wait for deployment and open the URL shown on the Pages settings page.
6. On Android Chrome, use ⋮ → Install app / Add to Home screen.

Note: gameplay is an original starter implementation and can be extended with levels, sound, enemies, and animations.
